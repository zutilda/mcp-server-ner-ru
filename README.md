# mcp-server-ner-ru

MCP-сервер для извлечения именованных сущностей и персональных данных из
русского текста.

## Назначение

Проект создаётся как выпускная квалификационная работа (ВКР) по программе
«Программная инженерия». Цель — дать языковым моделям и агентным системам
готовый инструмент, который по русскому тексту возвращает структурированный
список именованных сущностей и персональных данных, а не свободный ответ.

Проблема, которую решает проект: LLM хорошо понимают смысл текста, но
неустойчиво и невоспроизводимо выделяют сущности — при повторном запросе
границы упоминаний и нормальные формы меняются. Специализированный NER-модель
на базе Natasha работает детерминированно и локально, поэтому результат
воспроизводим и не зависит от внешних API.

Практический сценарий — обезличивание текста перед отправкой в языковую
модель. Компаниям нужны нейросети, но нельзя передавать им персональные
данные; сервер находит такие данные, заменяет их плейсхолдерами и возвращает
карту соответствий, по которой ответ модели можно восстановить в исходном виде.

## Что делает сервер

Сервер реализует протокол Model Context Protocol (MCP) и подключается к
LLM-клиентам (Claude Desktop, MCP Inspector, агентные фреймворки) по stdio.

Инструменты:

- `extract_entities` — находит сущности и возвращает их список с позициями;
- `redact_text` — заменяет персональные данные плейсхолдерами и возвращает
  карту соответствий;
- `restore_text` — выполняет обратную подстановку по карте и сообщает о
  потерянных и лишних маркерах.

Поддерживаемые категории:

- **PER** — персоналии, приведённые к именительному падежу;
- **LOC** — локации;
- **ORG** — организации;
- **PHONE** — телефоны, нормализованные к виду `+7XXXXXXXXXX`;
- **EMAIL** — адреса электронной почты;
- **PASSPORT** — серия и номер паспорта РФ;
- **INN** — ИНН из 10 или 12 цифр;
- **SNILS** — страховой номер индивидуального лицевого счёта;
- **OMS** — номер полиса обязательного медицинского страхования;
- **CARD** — номера банковских карт;
- **ADDRESS** — почтовые адреса;
- **BIRTHDATE** — даты рождения.

Для каждой сущности указываются тип, исходное упоминание, нормальная форма и
позиция в тексте, чтобы результат можно было проверить и сопоставить с
исходной строкой.

Числовые идентификаторы проверяются по контрольным суммам: ИНН, СНИЛС, полис
ОМС и номера карт. Без такой проверки любая последовательность цифр подходила
бы под шаблон, и обезличивание портило бы обычный текст.

## Технологический стек

- Python 3.12, управление зависимостями — `uv`
- `mcp` — серверная часть протокола MCP
- `natasha` — сегментация, морфология и NER для русского языка
- `pydantic` — схемы входных и выходных данных
- `pytest` — тесты

.

## Запуск

Требуется Python 3.12 и `uv`.

```bash
uv sync
uv run pytest
```

Сервер работает по stdio: stdout занят кадрами JSON-RPC, диагностические
сообщения выводятся в stderr. Запуск из корня репозитория:

```bash
uv run ner-mcp
```

Для MCP-хостов путь к репозиторию передаётся абсолютным, иначе хост запустит
сервер в своём рабочем каталоге:

```json
{
  "mcpServers": {
    "ner-mcp": {
      "command": "uv",
      "args": [
        "run",
        "--directory",
        "/absolute/path/to/mcp-server-ner-ru",
        "ner-mcp"
      ]
    }
  }
}
```

## Статус

Реализованы модели данных, контрольные суммы, извлечение контактов и
персональных данных, NER на Natasha, объединение источников с разрешением
пересечений, обратимое обезличивание и MCP-адаптер с тремя инструментами,
ресурсом таксономии и промптом. Покрытие тестами — 96 проверок; сервер
проверен живым запуском по stdio. Дальше — примеры использования и
