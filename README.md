# mcp-server-ner-ru

MCP-сервер для извлечения именованных сущностей из русского текста.

## Назначение

Проект создаётся как выпускная квалификационная работа (ВКР) по программе
«Программная инженерия». Цель — дать языковым моделям и агентным системам
готовый инструмент, который по русскому тексту возвращает структурированный
список именованных сущностей, а не свободный ответ.

Проблема, которую решает проект: LLM хорошо понимают смысл текста, но
неустойчиво и невоспроизводимо выделяют сущности — при повторном запросе
границы упоминаний и нормальные формы меняются. Специализированный NER-модель
на базе Natasha работает детерминированно и локально, поэтому результат
воспроизводим и не зависит от внешних API.

## Что делает сервер

Сервер реализует протокол Model Context Protocol (MCP) и подключается к
LLM-клиентам (Claude Desktop, MCP Inspector, агентные фреймворки) по stdio.

Основная возможность — инструмент `extract_entities`, который принимает
русский текст и возвращает:

- **PER** — персоналии, приведённые к именительному падежу;
- **LOC** — локации;
- **ORG** — организации;
- **контакты** — телефоны, email, URL, Telegram-адреса, извлечённые
  детерминированными регулярными выражениями.

Для каждой сущности указываются тип, исходное упоминание, нормальная форма и
позиция в тексте, чтобы результат можно было проверить и сопоставить с
исходной строкой.

## Технологический стек

- Python 3.12, управление зависимостями — `uv`
- `mcp` — серверная часть протокола MCP
- `natasha` — сегментация, морфология и NER для русского языка
- `pydantic` — схемы входных и выходных данных

├── .python-version       # версия интерпретатора

## Запуск

Требуется Python 3.12 и `uv`.

```bash
uv sync
uv run server.py
```

Сервер работает по stdio: stdout занят кадрами JSON-RPC, диагностические
сообщения выводятся в stderr.
